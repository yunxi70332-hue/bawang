## 1. 部署产物与目录结构

打包脚本收录且仅收录线上运行所需：

```
release/
├── server/                 # FastAPI 后端（app.py、routers/、services/、schemas…全量 .py）
├── web/dist/               # 前端构建产物（主 API 直接静态托管，无需 Node）
├── scripts/chagee_*.py     # 茶姬纯协议层（运行时 import，不含取证/逆向工具）
├── requirements.txt
└── docs/线上部署手册_v1.0.md
```

**不随包携带、需在服务器手工落位**（安全与数据边界）：

| 文件/目录 | 说明 |
|---|---|
| `account_system/data/secret.key` | JWT 签名密钥（缺省自动生成，但多进程/迁移须固定） |
| `account_system/data/proxy_config.json` | 代理出口配置——**含海量IP服务商凭证，已 .gitignore 且不入包**，服务器上手工配置（System 设置页或直接落文件） |
| `account_system/data/app.db` | 业务库（首次启动自动建表+种子 admin/Admin@123，**上线后立即改密**） |
| `account_system/data/accounts/` | 茶姬账号凭证目录（从开发机手工迁移） |

## 2. 环境要求与安装

- Python **3.12+**（Windows 开发机为 3.12；Linux 服务器同版次最佳）
- 依赖：`pip install -r requirements.txt`（FastAPI/SQLAlchemy/httpx/requests 等）
- 无需 Node/构建链（dist 已随包）；无需外部数据库/消息队列（SQLite WAL + 内置队列）

```bash
# ① 解压到 /opt/chagee（示例）
unzip release_v1.0_*.zip -d /opt/chagee && cd /opt/chagee
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

# ② 数据目录落位（首次）
mkdir -p account_system/data/logs
# 迁移/创建 secret.key、proxy_config.json（如启用代理）、accounts/ 凭证目录

# ③ 启动主 API（管理面 + 前端托管 + 全部后台线程/worker）
cd account_system/server
nohup python -m uvicorn app:app --host 127.0.0.1 --port 8000 >> ../../data/logs/api.log 2>&1 &

# ④ 启动 H5 收银台进程（局域网/公网支付页，仅 /pay/* 公开路由）
nohup python -m uvicorn pay_portal:app --host 0.0.0.0 --port 8010 >> ../../data/logs/portal.log 2>&1 &
```

生产建议：systemd 两个 unit（`chagee-api.service` / `chagee-portal.service`，Restart=always）；主 API 保持 127.0.0.1 由 Nginx/Caddy 反代终止 TLS，收银台 8010 视支付链路可达性决定是否反代。

## 3. 环境变量（全部有默认值，按需覆盖）

| 变量 | 默认 | 线上建议 |
|---|---|---|
| CHAGEE_ORDER_WORKERS | 2 | 按单量调（每 worker 独立线程） |
| CHAGEE_PAYWATCH_INTERVAL_SECONDS | 2 | 保持（支付收口实时性） |
| CHAGEE_RECONCILE_INTERVAL_SECONDS | 60 | 保持 |
| CHAGEE_BACKUP_INTERVAL_SECONDS | 86400 | 保持；备份落 data/backups/（纳管到系统备份） |
| CHAGEE_KEEPALIVE_THREAD | 1 | 保持（每天 10:30 保活跃） |
| CHAGEE_MINT_PROVIDER | protocol | 保持（纯协议收银台铸造） |
| CHAGEE_INTAKE_RATE_LIMIT | 120 | 按外部对接方调 |
| CHAGEE_TUNNEL_ENABLED | 1 | **线上无云手机需求置 0** |
| CHAGEE_PROXY_CHECK_INTERVAL_SECONDS | 30 | 启用代理则保持 |

## 4. 香港服务器专项检查清单

1. **海量IP白名单**：把服务器出口 IP 加入海量IP后台白名单（proxy_settings.md §57 明确要求，漏做则代理提取全失败→自动回退直连）。
2. **出口 IP 固定性**：若走 NAT 弹性出口，先固定再配白名单。
3. **时区**：全系统本地时间口径（datetime.now()），建议 `timedatectl set-timezone Asia/Shanghai` 保持与开发机一致（券剩 N 天为自然日口径）。
4. **直连可达性**：CHAGEE_PROXY_HEALTHCHECK_URL 探测以真实茶姬网关可达为准；香港直连茶姬域通常可达，代理失败 fail-open 直连不影响可用性。
5. **8010 收银台**：支付页须手机可达——防火墙放行/Nginx 反代 `^/pay/`；管理面 8000 **不得**直接暴露公网。
