## 2026-10-03 · 优惠券查询页小改：每页条数选择 + 账号列显示手机号

**影响范围**：仅前端 `account_system/web/src/views/CouponQueryView.vue` 单文件 + 重新构建的 `web/dist`，**后端零改动**。页面：`/ops/coupons`。

### 1. 分页区域新增每页显示数量下拉（需求背景：46 条券翻 3 页不便）

- 「本次查询明细」与「券档案库」两个分页器均增加「20条/页 / 50条/页」下拉选择（Element Plus 分页器 `sizes` 插槽，全局 zh-cn 语言包渲染中文文案）。
- 切换条数后自动回到第 1 页（避免停留在越界页码）；「本次查询明细」为前端本地切片立即生效；「券档案库」按新条数重新请求服务端，并加请求序号防竞态——快速连续切换时丢弃过期响应，旧数据不会覆盖新状态。
- **选择状态持久化**：写入 `localStorage`（键 `chagee.couponQuery.livePageSize` / `chagee.couponQuery.archivePageSize`，两分页器独立记忆），页面刷新或跳转后返回仍保持，档案库首屏加载即使用记忆值。

### 2. 明细表「账号」列改为显示具体手机号

- 原显示「1#2」「郭#4」式短标签（label#id），无法直观对应账号；现按券条目 `account_id` → 账号列表 `phone_masked` 前端映射，显示完整 11 位手机号。
- 后端券条目只带 `account_id`/`account_label`，手机号复用页面已加载的账号列表，无需接口改动；账号已删除等映射不到的场景回退显示原短标签。
- 单账号查询模式该列本就隐藏（仅全量遍历显示），「归属」列（可用/历史）不变。

### 3. 验证与部署

- 本地浏览器端到端：切 50条/页 → 明细页全量一页展示；档案库请求 `page_size=50`、49 条一页、页码收敛为 1；刷新后两分页器均保持 50条/页。
- 生产接口实测（103.117.121.126，带鉴权）：`page_size=20 → 20 条`、`page_size=50 → 50 条`（接口原生支持 1–100，未改代码）。
- 线上部署：经宝塔通道替换 `/www/wwwroot/chagee/account_system/web/dist`（42 文件，sha256 校验一致；旧版备份 `dist.bak_20261003_pagersize`、`dist.bak_phoneacct`）。静态托管按请求读盘，未重启服务；浏览器访问需 Ctrl+F5 强刷一次。
