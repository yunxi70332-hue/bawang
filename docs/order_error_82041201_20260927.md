# 下单报错 [82041201] 网络异常 诊断定案（2026-09-27 凌晨）

## 结论（一句话）

**"网络异常，请稍后重试"是 trade 服务校验失败的兜底文案，不是网络问题；本次根因是「对已打烊门店做 settlePrice 试算/下单」。** 协议客户端代码无缺陷——同一账号、同一代码，换营业中门店立即成功。

## 证据链

1. **错误透传路径**：`chagee_client.py:199` —— HTTP 200 + 响应体 `errcode/errmsg` 原样透传，`thirdTraceId` 空（未进入正常业务链路）；工作台 502 包装文案在 `orders.py` `_fail`。
2. **报错环节锁定**：createOrder 的 ChageeError 会被包成 `OrderHangError`→409「下单结果不确定」；出现「协议错误: [82041201]」说明失败发生在 **settle（settlePrice/calculatePrice/whoami）阶段**，订单尚未提交。
3. **同码族实证**：同一兜底文案下错误码不固定——本次复现 91010009、用户 82041201、历史真实 App commitPay 8202020200007（`output/trade_samples` 抓包，validationResult=DEFAULT_INVALID）。**错误码不是稳定信号，"网络异常"文案 + settle 阶段才是**。
4. **门店营业时间（flows 实证 `store/detail.businessInfo.diningInfo.runningTime`）**：
   - CN08121 广东佛山顺德龙江沃达百货店：**09:00–22:29**（09-27 01:30 已打烊 → 试算必败）
   - CN07078 湖南衡阳南华大学东门店：**05:00–04:00**（跨夜营业 → 01:29 App 成功、01:4x 探针成功）
   - 昨晚 22:28 成功单恰在 CN08121 打烊前 1 分钟，此后所有"网络异常"都发生在打烊时段。
5. **同分钟 A/B**：01:29 真实 App（CN07078）成功 vs 01:32 探针（CN08121）失败——同宿主、同出口 IP、同账号体系，排除 IP 风控/签名/时段封禁，唯一变量是门店。

## 排除项

- ❌ 签名/加密问题：trade 域全程无 sign 头（wire 定案），且同一代码昨晚成功过。
- ❌ IP 风控：calculatePrice/whoami 同 IP 正常；真实 App 同 IP 成功。
- ❌ token 失效：whoami 两账号均正常（401 才是踢登语义）。
- ❌ 服务端整体故障：App 同期 settle 成功。
- ❌ sk/header 差异：未变更过且非失败边界条件。

## 附带发现与处置

1. **云手机"网络不给力"（独立故障，已修复）**：第 3 次 adb 断线后遗症——`adb reverse` 隧道全丢（`reverse --list` 空）而 hosts 劫持（gw/gj-api/api-cn/h5-sea → 127.0.0.1）与全局代理残留 → App 业务域名黑洞。处置：`adb reverse tcp:443 tcp:8443`、`tcp:8080 tcp:18080` 重建后，App 全业务接口恢复 200。mitmdump 双进程（8443 reverse/18080 regular）全程存活未动。
2. **真实 App 在云手机上登录的是第三个账号 1282813116**（非 DB 内 1193099363/1190018250），注意单会话语义互踢风险。
3. **改动**：`account_system/server/routers/orders.py` `_fail`——ChageeError 文案含"网络异常"时追加门店打烊提示；新增只读探针 `scripts/probe_82041201.py`（whoami→calculatePrice→settlePrice 三跳定位，绝不 createOrder）。

## 运维建议

- 下单/试算前核对门店营业时间（`runningTime` 结构：`[{"worktime":[{"time":["HH:MM","HH:MM"]}],"workweek":[...]}]`，注意跨夜区间如 05:00–04:00）；凌晨自动化下单选跨夜门店（如 CN07078）或等营业时段。
- 遇"网络异常"文案先跑 `python scripts/probe_82041201.py` 三跳定位，再区分：打烊（换门店即好）/参数校验（对照 wire 模板）/真·服务端故障（App 也失败）。
